# 简介
> 此项目用于演示使用easyapi提供的加签、验签功能，以及如何定制自己的加签验签算法。
>
> 1. 请求参数验签，使用`@RequiredSign(scope = SignScope.REQUEST)`注解修饰接口即可
> 2. 响应信息加签，使用`@RequiredSign(scope = SignScope.RESPONSE)`注解修饰接口即可
> 3. 指定自定义加签算法，使用`@RequiredSign(scope = SignScope.REQUEST, type = Md5SignEncryptHandler.class)`注解修饰接口即可，`Md5SignEncryptHandler`是自定义验签算法的并实现了`SignEncryptHandler`的接口。
> 4. 指定自定义验签算法，使用`@RequiredSign(scope = SignScope.RESPONSE, type = Md5SignEncryptHandler.class)`注解修饰接口即可

## 4 演示代码解析

### 4.1 使用默认的SHA1进行加签验签

> 加签验签的使用主要分两种应用场景：
>
> 1. 对api调用者传递过来的接口请求信息和数字签名进行验签
> 2. 将API返回信息生成数字签名后一并返回给接口调用者，接口调用者拿到后进行验签
> 3. 请求响应均需要进行数字签名处理
>
> 示例代码如下所示。

> 差异说明：原文档示例的`TestSignController`（`testRequestCheckSign`、`testResponseSign`、`testIgnoreRequestFiledSign`，POST请求体为`SignTestRequest`/`IgnoreRequestFiledSignRequest`）在本模块中不存在，实际接口为`SignController`（包`com.pddon.framework.demo.easyapi.sign`，路径前缀`/sign`），DTO改为`SignResponse`和`IgnoreFieldRequest`。

- 接口源码`SignController.java`

```java
package com.pddon.framework.demo.easyapi.sign;

import org.springframework.web.bind.annotation.GetMapping;
import org.springframework.web.bind.annotation.PostMapping;
import org.springframework.web.bind.annotation.RequestBody;
import org.springframework.web.bind.annotation.RequestMapping;
import org.springframework.web.bind.annotation.RequestParam;
import org.springframework.web.bind.annotation.RestController;

import com.pddon.framework.demo.easyapi.sign.dto.IgnoreFieldRequest;
import com.pddon.framework.demo.easyapi.sign.dto.SignResponse;
import com.pddon.framework.demo.easyapi.sign.security.Md5SignEncryptHandler;
import com.pddon.framework.easyapi.annotation.RequiredSign;
import com.pddon.framework.easyapi.consts.SignScope;

/**
 * 接口验签/加签示例。
 */
@RestController
@RequestMapping("/sign")
public class SignController {

    /**
     * 仅校验请求签名，使用默认 SHA1 算法。
     */
    @GetMapping("/request")
    @RequiredSign(scope = SignScope.REQUEST)
    public String requestSign(@RequestParam String name, @RequestParam String phone) {
        return "SUCCESS:" + name + ":" + phone;
    }

    /**
     * 仅对响应加签，使用默认 SHA1 算法。
     */
    @GetMapping("/response")
    @RequiredSign(scope = SignScope.RESPONSE)
    public SignResponse responseSign(@RequestParam String name) {
        SignResponse response = new SignResponse();
        response.setDesc("response sign");
        response.setPhone("13800000000");
        response.setTest("name=" + name);
        return response;
    }

    /**
     * 请求验签 + 响应加签，使用默认 SHA1 算法。
     */
    @GetMapping("/both")
    @RequiredSign(scope = SignScope.BOTH)
    public SignResponse both(@RequestParam String name) {
        SignResponse response = new SignResponse();
        response.setDesc("both sign");
        response.setPhone("13900000000");
        response.setTest("name=" + name);
        return response;
    }

    /**
     * 演示 @IgnoreSign：ignoreMe 字段不参与请求验签。
     */
    @PostMapping("/ignoreField")
    @RequiredSign(scope = SignScope.REQUEST)
    public String ignoreField(@RequestBody IgnoreFieldRequest request) {
        return "SUCCESS:" + request.getDesc() + ":" + request.getIgnoreMe();
    }

    /**
     * 自定义 MD5 签名算法，请求与响应均使用 MD5。
     */
    @GetMapping("/customMd5")
    @RequiredSign(scope = SignScope.BOTH, type = Md5SignEncryptHandler.class)
    public SignResponse customMd5(@RequestParam String name) {
        SignResponse response = new SignResponse();
        response.setDesc("md5 sign");
        response.setPhone("13700000000");
        response.setTest("name=" + name);
        return response;
    }
}
```

* 默认SHA1处理器的显式注册`SignHandlerConfig.java`

> 框架默认的`SignEncryptHandler` Bean带有`@ConditionalOnMissingBean`条件，工程中存在任意自定义`SignEncryptHandler`（如`Md5SignEncryptHandler`）时，默认SHA1处理器不会再被注册，而`@RequiredSign`默认的`type`仍指向`Sha1SignEncryptHandler`，因此示例显式注册了该Bean。

```java
package com.pddon.framework.demo.easyapi.sign;

import org.springframework.context.annotation.Bean;
import org.springframework.context.annotation.Configuration;

import com.pddon.framework.easyapi.encrypt.impl.Sha1SignEncryptHandler;

@Configuration
public class SignHandlerConfig {

    /**
     * Bean 名称保持为 signEncryptHandler，兼容框架 signManager 对该名称的注入。
     */
    @Bean
    public Sha1SignEncryptHandler signEncryptHandler() {
        return new Sha1SignEncryptHandler();
    }
}
```

### 4.2 使用自定义的算法进行加签验签
* 新增自定义签名算法处理器`Md5SignEncryptHandler.java`

```java
package com.pddon.framework.demo.easyapi.sign.security;

import org.springframework.stereotype.Component;

import com.pddon.framework.easyapi.encrypt.SignEncryptHandler;
import com.pddon.framework.easyapi.utils.EncryptUtils;

/**
 * 自定义 MD5 签名算法处理器。
 * 在接口上通过 @RequiredSign(type = Md5SignEncryptHandler.class) 指定后生效。
 */
@Component
public class Md5SignEncryptHandler implements SignEncryptHandler {

    @Override
    public String sign(String secret, String body) {
        return EncryptUtils.encryptMD5Hex(secret, body);
    }
}
```

> 只需要将前面示例中的`@RequiredSign(scope = SignScope.REQUEST, type = Md5SignEncryptHandler.class)`的type指定为该类即可实现自定义验签算法，`SignController#customMd5`即为`@RequiredSign(scope = SignScope.BOTH, type = Md5SignEncryptHandler.class)`的完整示例。

* 请求示例

```shell
curl "http://localhost:8085/sign/customMd5?appId=webApp&channelId=default&name=demo&sign=xxx&timestamp=1700000000000"
```

### 4.3 验签防重放（可选，默认关闭）

> 开启`easyapi.sign.replay-protection.enabled=true`后，验签在原有等值比对之上增加两步校验：
>
> 1. **时间窗**：`timestamp`（毫秒）与服务器时间的偏差不得超过`timestamp-window-seconds`（默认300秒），超出返回`ERROR_SIGN(130005)`；
> 2. **nonce一次性**：请求必须携带`nonce-param`（默认`nonce`）指定的参数，且该参数**必须参与签名**；验签通过后由服务端原子消费nonce，重复使用返回`REPLAY_ATTACK(130008)`；nonce为空或长度超过`nonce-max-length`返回`ERROR_SIGN(130005)`。
>
> 签名内容变为：`timestamp + 排序拼接后的参数(含nonce) + timestamp`。未开启防重放时（默认）客户端无需任何改动，旧签名仍可重放，行为与此前完全一致。
>
> nonce通过统一状态存储`DistributedStateStore`消费：未接入Redis时为有界本地缓存（`nonce-cache-size`上限 + `nonce-ttl-seconds`过期），单JVM有效；接入Redis后为`SET NX EX`，跨实例一次性消费。

* 客户端生成签名示例

```java
Map<String, String> params = new TreeMap<>();
params.put("name", "alice");
params.put("phone", "13800000000");
params.put("nonce", nonce); // nonce 作为普通业务参数参与签名
String timestamp = String.valueOf(System.currentTimeMillis());
String sign = EncryptUtils.encryptSHA1Hex(secret, timestamp + EncryptUtils.sortAndMontage(params) + timestamp);
```

* 请求示例（`api-sign-demo`测试以`--easyapi.sign.replay-protection.enabled=true`启动应用）

```shell
# 窗口内、nonce首次使用：code=0
curl "http://localhost:8085/sign/request?appId=webApp&channelId=default&name=alice&phone=13800000000&nonce=abc-1&timestamp=<当前毫秒>&sign=<签名>"

```
