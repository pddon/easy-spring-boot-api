<center><h1>easy-spring-boot-api框架国际化响应信息示例</h1></center>

# 简介
> 此项目用于演示如何使用easyapi提供的响应信息国际化能力。有如下几种场景:
>
> 1. 错误提示国际化，easyapi框架层自动处理
> 2. 通过接口语言类型locale参数进行指定，响应信息自动翻译，使用`@LanguageTranslate`注解
> 3. 响应信息，翻译成指定语言`@LanguageTranslate(locale = "en_US")`
> 4. 使用国际化翻译器手动翻译业务内容，使用国际化管理器`LanguageTranslateManager`手动翻译

* [demo源码传送门](../../../easy-spring-boot-api-simple-demos/translate-resp-language-demo)

### 3.2 国际化翻译配置信息

> 你可以选择都配置在默认的`i18n/messages/messages`文件中，也可以分类进行存放。

* 自定义系统错误码国际化翻译

    > 下面是自定义basename`i18n/custom/systemErrorCodeInfo`下的实际内容
    >
    > `systemErrorCodeInfo_en_US.properties`

```properties
# 自定义 messages basename
# 注意：框架会把内置 META-INF/i18n/easyApiMessages 前置到 spring.messages.basename，
# 且先出现的 basename 优先，因此这里同名的 system.invalidParam 不会覆盖内置提示，
# 仅新增的 key（如 demo.customOnly）可以生效。
system.invalidParam=[self-defined]this invalid param{0}[{1}]
demo.customOnly=[custom bundle]only in custom
```

    >
    > `systemErrorCodeInfo_zh_CN.properties`

```properties
# 自定义 messages basename
# 注意：框架会把内置 META-INF/i18n/easyApiMessages 前置到 spring.messages.basename，
# 且先出现的 basename 优先，因此这里同名的 system.invalidParam 不会覆盖内置提示，
# 仅新增的 key（如 demo.customOnly）可以生效。
system.invalidParam=[自定义]这是无效参数{0}[{1}]
demo.customOnly=[自定义bundle]only in custom
```

> 差异说明：原文档示例认为在自定义bundle中定义同名的`system.invalidParam`即可覆盖框架默认的系统错误码提示，但实际框架会把内置的`META-INF/i18n/easyApiMessages`前置到`spring.messages.basename`，先出现的basename优先，因此这里同名的`system.invalidParam`不会覆盖内置提示，只有新增的key（如`demo.customOnly`）可以生效。

## 4 源码示例说明

### 4.1 响应信息国际化

> 我们可以对响应内容的全部字符串信息进行自动国际化翻译，也可以只对其中的某些字段进行国际化翻译。

> 差异说明：原文档示例的`TestTranslateResponseController`（`getLanguageInfo`、`getLanguageFieldInfo`、`getEnglishLicence`）在本模块中不存在，实际代码统一为`TranslateController`（包`com.pddon.framework.demo.easyapi.translate`，路径前缀`/translate`），对应接口为`GET /translate/object`、`GET /translate/fields`、`GET /translate/license`。

* 接口源码`TranslateController.java`

```java
package com.pddon.framework.demo.easyapi.translate;

import javax.validation.Valid;
import javax.validation.constraints.NotEmpty;

import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.validation.annotation.Validated;
import org.springframework.web.bind.annotation.GetMapping;
import org.springframework.web.bind.annotation.PostMapping;
import org.springframework.web.bind.annotation.RequestBody;
import org.springframework.web.bind.annotation.RequestMapping;
import org.springframework.web.bind.annotation.RequestParam;
import org.springframework.web.bind.annotation.RestController;

import com.pddon.framework.demo.easyapi.translate.dto.CustomResponse;
import com.pddon.framework.demo.easyapi.translate.dto.LanguageInfoDto;
import com.pddon.framework.demo.easyapi.translate.dto.LicenseDto;
import com.pddon.framework.demo.easyapi.translate.dto.ValidateRequest;
import com.pddon.framework.easyapi.LanguageTranslateManager;
import com.pddon.framework.easyapi.exception.BusinessException;

/**
 * 接口响应国际化翻译示例。
 */
@RestController
@RequestMapping("/translate")
@Validated
public class TranslateController {

    @Autowired
    private LanguageTranslateManager languageTranslateManager;

    /**
     * 类级 @LanguageTranslate：整个对象按请求 locale 自动翻译。
     */
    @GetMapping("/object")
    public LanguageInfoDto object(@RequestParam(name = "info", required = false) String info) {
        LanguageInfoDto dto = new LanguageInfoDto();
        dto.setInfo(info == null ? "danyuan.info" : info);
        dto.setName("danyuan.name");
        return dto;
    }

    /**
     * 字段级 @LanguageTranslate：只翻译 name/info/tags。
     */
    @GetMapping("/fields")
    public CustomResponse fields() {
        CustomResponse response = new CustomResponse();
        response.setName("danyuan.name");
        response.setAge(22);
        response.setSex(true);
        response.setInfo("danyuan.info");
        response.setTags("danyuan.tags");
        return response;
    }

    /**
     * 字段固定翻译成英文，不依赖请求 locale。
     */
    @GetMapping("/license")
    public LicenseDto license() {
        LicenseDto dto = new LicenseDto();
        dto.setLicence("LICENSE");
        return dto;
    }

    /**
     * 使用 LanguageTranslateManager 手动翻译。
     */
    @GetMapping("/manual")
    public String manual(@RequestParam(name = "infoDict", required = false) String infoDict,
                         @RequestParam(name = "locale", required = false, defaultValue = "en_US") String locale) {
        String key = infoDict == null || infoDict.isEmpty() ? "danyuan.info" : infoDict;
        return languageTranslateManager.get(key, locale);
    }

    /**
     * 业务错误信息按请求 locale 自动翻译。
     */
    @PostMapping("/login")
    public void login(@RequestParam @NotEmpty String account, @RequestParam @NotEmpty String password) {
        if (!"admin".equals(account)) {
            throw new BusinessException("USER_ACCOUNT_NOT_FOUND").setParam(account);
        }
        if (!"123456".equals(password)) {
            throw new BusinessException("USER_PASSWORD_ERROR");
        }
    }

    /**
     * 参数校验错误信息按请求 locale 自动翻译（自定义系统错误码提示）。
     */
    @PostMapping("/invalidBody")
    public String invalidBody(@Valid @RequestBody ValidateRequest request) {
        return "OK:" + request.getAccount();
    }
}
```

### 4.2 业务错误自动翻译

> 异常信息也能自动翻译，无需做任何处理，只需要接口调用者指定自己需要的语言类型即可，框架自动进行转换。

> 差异说明：原文档示例的`TestTranslateBusinessErrorController`（`POST getLanguageInfo`，参数由`@Valid`直接修饰）在本模块中不存在，等价接口为`POST /translate/login`；另外新增`POST /translate/invalidBody`用于演示DTO参数校验错误信息按`locale`自动翻译。

* 接口源码（`TranslateController.java`节选）

```java
    @PostMapping("/login")
    public void login(@RequestParam @NotEmpty String account, @RequestParam @NotEmpty String password) {
        if (!"admin".equals(account)) {
            throw new BusinessException("USER_ACCOUNT_NOT_FOUND").setParam(account);
        }
        if (!"123456".equals(password)) {
            throw new BusinessException("USER_PASSWORD_ERROR");
        }
    }

    @PostMapping("/invalidBody")
    public String invalidBody(@Valid @RequestBody ValidateRequest request) {
        return "OK:" + request.getAccount();
    }
```

* 参数校验DTO`ValidateRequest.java`

```java
package com.pddon.framework.demo.easyapi.translate.dto;

import java.io.Serializable;

import javax.validation.constraints.NotEmpty;

/**
 * 用于演示 DTO 参数校验错误信息走自定义系统错误码翻译。
 */
public class ValidateRequest implements Serializable {

    private static final long serialVersionUID = 1L;

    @NotEmpty
    private String account;

    public String getAccount() {
        return account;
    }

    public void setAccount(String account) {
        this.account = account;
    }
}
```

* 请求示例

```shell

curl -X POST -H "Content-Type: application/json" -d "{\"account\":\"\"}" "http://localhost:8087/translate/invalidBody?appId=webApp&channelId=default&locale=en_US"
```

### 4.3 手动翻译

> 也可以注入`LanguageTranslateManager`语言翻译管理器进行手动翻译。

* 接口源码（`TranslateController.java`节选）

```java
    @GetMapping("/manual")
    public String manual(@RequestParam(name = "infoDict", required = false) String infoDict,
                         @RequestParam(name = "locale", required = false, defaultValue = "en_US") String locale) {
        String key = infoDict == null || infoDict.isEmpty() ? "danyuan.info" : infoDict;
        return languageTranslateManager.get(key, locale);
    }
```

* 请求示例

```shell
curl "http://localhost:8087/translate/manual?appId=webApp&channelId=default&locale=en_US"
curl "http://localhost:8087/translate/manual?appId=webApp&channelId=default&infoDict=danyuan.name&locale=zh_CN"
```
