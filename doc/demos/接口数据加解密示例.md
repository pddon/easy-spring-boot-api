<center><h1>easy-spring-boot-api框架请求响应数据加解密使用示例</h1></center>

# 简介
> 此项目用于演示easyapi如何提供统一全自动化的API隐私数据保护，并且可以做到业务无感和灵活指定数据加解密算法。
>
> 请求数据加密使用`@Decrypt`注解，响应信息加密使用`@Encrypt`注解，使用自定义算法进行加解密请实现`DataEncryptHandler`接口，注解中指定即可。
>
> 1. 请求数据解密
> 2. 响应信息加密
> 3. 指定自定义解密算法
> 4. 指定自定义加密算法

* [demo源码传送门](../../../easy-spring-boot-api-simple-demos/api-private-data-demo)

## 4 演示代码解析

### 4.1 使用默认的AES进行加解密

> API数据的加解密的使用主要分两种应用场景：
>
> 1. 对api调用者传递过来的接口请求内的隐私信息进行解密，然后交由业务去处理，easyapi对业务屏蔽了加解密的过程，业务可以直接使用明文进行处理
>
> 2. 将API返回隐私信息加密后再返回给接口调用者，接口调用者拿到后再进行解密后处理
>
> 示例代码如下所示。
>

> 差异说明：原文档示例的`TestEncryptAndDecryptController`（`testDecryptParamAndResponse`、`testEncryptListResponseData`、`testEncryptStringResponse`）和`TestCustomEncryptAndDecryptController`在本模块中不存在，实际代码统一为`PrivateDataController`（包`com.pddon.framework.demo.easyapi.privateinfo`，路径前缀`/private`），AES示例接口为`/private/aes/*`，RSA示例接口为`/private/rsa/*`。

- 接口源码`PrivateDataController.java`

```java
package com.pddon.framework.demo.easyapi.privateinfo;

import java.util.ArrayList;
import java.util.List;

import org.springframework.web.bind.annotation.GetMapping;
import org.springframework.web.bind.annotation.RequestMapping;
import org.springframework.web.bind.annotation.RequestParam;
import org.springframework.web.bind.annotation.RestController;

import com.pddon.framework.demo.easyapi.privateinfo.component.RsaDataEncryptHandler;
import com.pddon.framework.demo.easyapi.privateinfo.dto.SimpleTextDto;
import com.pddon.framework.demo.easyapi.privateinfo.dto.UserInfoDto;
import com.pddon.framework.easyapi.annotation.Decrypt;
import com.pddon.framework.easyapi.annotation.Encrypt;

/**
 * 接口数据加解密示例。
 */
@RestController
@RequestMapping("/private")
public class PrivateDataController {

    /**
     * 默认 AES：解密请求参数 desc，并加密整个响应对象。
     */
    @GetMapping("/aes/paramAndResponse")
    @Encrypt
    public UserInfoDto aesParamAndResponse(@RequestParam("desc") @Decrypt String desc) {
        return buildUser(desc);
    }

    /**
     * 默认 AES：仅加密 UserInfoDto.desc 字段，列表其他字段保持明文。
     */
    @GetMapping("/aes/list")
    public List<UserInfoDto> aesList() {
        List<UserInfoDto> list = new ArrayList<>();
        list.add(buildUser("list item 1"));
        list.add(buildUser("list item 2"));
        return list;
    }

    /**
     * 默认 AES：方法级 @Encrypt 对整个 String 响应加密。
     */
    @GetMapping("/aes/string")
    @Encrypt
    public String aesStringResponse() {
        return "This just a string response encrypt test !";
    }

    /**
     * 自定义 RSA：解密请求参数，并加密响应对象的所有字符串字段。
     */
    @GetMapping("/rsa/paramAndResponse")
    @Encrypt(type = RsaDataEncryptHandler.class)
    public SimpleTextDto rsaParamAndResponse(
            @RequestParam("desc") @Decrypt(type = RsaDataEncryptHandler.class) String desc) {
        SimpleTextDto dto = new SimpleTextDto();
        dto.setUsername("danyuan");
        dto.setDesc(desc);
        return dto;
    }

    /**
     * 自定义 RSA：方法级 @Encrypt 对整个 String 响应加密。
     */
    @GetMapping("/rsa/string")
    @Encrypt(type = RsaDataEncryptHandler.class)
    public String rsaStringResponse() {
        return "This just a RSA string response encrypt test !";
    }

    private UserInfoDto buildUser(String desc) {
        UserInfoDto user = new UserInfoDto();
        user.setUsername("danyuan");
        user.setAge(18);
        user.setDesc(desc);
        return user;
    }
}
```

### 4.2 使用自定义的算法进行加解密
* 新增自定义加解密算法处理器`RsaDataEncryptHandler.java`

```java
package com.pddon.framework.demo.easyapi.privateinfo.component;

import java.security.KeyPair;
import java.security.KeyPairGenerator;
import java.security.PrivateKey;
import java.security.PublicKey;
import java.util.Base64;

import javax.crypto.Cipher;

import org.springframework.stereotype.Component;

import com.pddon.framework.easyapi.encrypt.DataEncryptHandler;

/**
 * 自定义 RSA 加解密处理器。
 */
@Component
public class RsaDataEncryptHandler implements DataEncryptHandler {

    private static final String TRANSFORMATION = "RSA/ECB/PKCS1Padding";

    private final KeyPair keyPair;

    public RsaDataEncryptHandler() {
        try {
            KeyPairGenerator generator = KeyPairGenerator.getInstance("RSA");
            generator.initialize(1024);
            this.keyPair = generator.generateKeyPair();
        } catch (Exception e) {
            throw new IllegalStateException("初始化 RSA 秘钥对失败", e);
        }
    }

    public String getPublicKeyBase64() {
        return Base64.getEncoder().encodeToString(keyPair.getPublic().getEncoded());
    }

    public String getPrivateKeyBase64() {
        return Base64.getEncoder().encodeToString(keyPair.getPrivate().getEncoded());
    }

    @Override
    public String encrypt(String appId, String channelId, String userId, String content) throws Throwable {
        return encrypt(content, keyPair.getPublic());
    }

    @Override
    public String decrypt(String appId, String channelId, String userId, String content) throws Throwable {
        return decrypt(content, keyPair.getPrivate());
    }

    public static String encrypt(String content, PublicKey publicKey) throws Exception {
        Cipher cipher = Cipher.getInstance(TRANSFORMATION);
        cipher.init(Cipher.ENCRYPT_MODE, publicKey);
        return Base64.getEncoder().encodeToString(cipher.doFinal(content.getBytes("UTF-8")));
    }

    public static String decrypt(String content, PrivateKey privateKey) throws Exception {
        Cipher cipher = Cipher.getInstance(TRANSFORMATION);
        cipher.init(Cipher.DECRYPT_MODE, privateKey);
        byte[] plain = cipher.doFinal(Base64.getDecoder().decode(content));
        return new String(plain, "UTF-8");
    }
}
```

> 差异说明：原文档示例的`RSADataEncryptHandler`通过`SecretManager`读取`application.yml`中`keyPair`的`publicSecret`/`privateSecret`做RSA加解密，并依赖`utils/RSAEncryptUtil`；本模块的实际类名是`RsaDataEncryptHandler`（包`com.pddon.framework.demo.easyapi.privateinfo.component`），为了工程自包含改为在进程内生成一对RSA秘钥，不再读取`keyPair`配置，也不存在`RSAEncryptUtil`工具类。实际项目的做法可参考原示例，从`SecretManager`读取秘钥对。

> 测试接口`PrivateDataController`通过`@Encrypt(type = RsaDataEncryptHandler.class)`和`@Decrypt(type = RsaDataEncryptHandler.class)`指定自定义算法，对应接口为`/private/rsa/paramAndResponse`和`/private/rsa/string`。
