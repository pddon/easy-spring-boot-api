# 简介
> 此项目用于演示如何使用easyapi提供的统一错误处理机制灵活应对业务中的异常场景。主要有以下几种场景：
>
> 1. 可以区分错误码类型，easyapi将api的错误码分为两大类，系统错误码和业务错误码。系统错误码用以描述API的常见通用性错误提示，例如：用户调用的接口不存在；业务错误码用以描述业务中的异常场景，比如：用户账号不存在，登录失败！
> 2. 系统错误码保持有限的个数，只存在数值型的码值，各个子系统中系统错误码均保持一致；
> 3. 业务错误码可以按数值型码值的区间对不同的子系统进行分段，也支持字符串形式的码值；
> 4. 业务错误码可以灵活自定义，提前配置字符串形式的码值可以做到自动生成数字型的码值，如果不指定字符串的码值，将使用统一的默认业务数值型码值；
> 5. 系统错误码和业务错误码均可以灵活自定义码值，用来兼容旧系统的的错误码；
>
> 错误码均可以通过使用抛出业务异常的方式进行接口返回，easyapi将自动对这些异常进行处理，然后统一返回到接口调用者。

## 2 启用EasyApi框架

```java
package com.pddon.framework.demo.easyapi.startup;

import org.springframework.boot.SpringApplication;
import org.springframework.boot.autoconfigure.SpringBootApplication;
import org.springframework.context.annotation.ComponentScan;

import com.pddon.framework.easyapi.annotation.EnableEasyApi;

/**
 * 错误码示例启动类。
 */
@SpringBootApplication
@ComponentScan(basePackages = "com.pddon.framework.demo.easyapi")
@EnableEasyApi
public class Startup {

    public static void main(String[] args) {
        SpringApplication.run(Startup.class, args);
    }
}
```

## 3 配置信息

> 错误码配置信息如下`application.yml`

```yaml
server:
  port: 8088
spring:
  application:
    name: error-code-demo
easyapi:
  basePackages: com.pddon.framework.demo.easyapi
  api:
    channels:
      default:
        webApp:
          secret: NKVNcuwwEF76622A
  error: #错误码相关配置
    #自定义系统错误码值，格式【枚举名：数值】
    #注意：BusinessErrorCodeInterpreterImpl.getSystemCodes() 依赖该配置不为空，
    #未配置时会抛 NullPointerException，因此示例中至少配置一项。
    systemErrorCodes:
      NOT_FOUND: 404
    #业务错误码默认起始值
    businessCodeStart: 200001
    #业务错误码默认最大值
    businessCodeEnd: 999999
    #业务异常错误码值
    businessErrorCodes:
      #不指定 code 时按名称 HASH 生成 200001-999999 区间的业务码
      USER_ACCOUNT_NOT_FOUND.desc: "用户账号[{0}]未找到!"
      # 自定义业务错误码值
      USER_PASSWORD_ERROR:
        code: 200006
        desc: "密码错误，请检查！"
```

> 业务错误码的中文提示同时来自`i18n/messages/messages_zh_CN.properties`（英文为`messages_en_US.properties`），例如：

```properties
USER_ACCOUNT_NOT_FOUND=用户账号[{0}]未找到!
USER_PASSWORD_ERROR=密码错误，请检查！
```

## 4 演示代码解析

### 4.1 业务异常使用示例

> 业务异常的使用主要分两种应用场景：
>
> 1. 需要特定的业务异常码值标识，客户端需要使用特定的码值做对应的逻辑处理
> 2. 只需要简单提示错误信息即可，没必要指定特殊错误码值
>
> 示例代码如下所示。

> 差异说明：原文档示例的`TestThrowBusinessErrorController`（`POST login`、`GET promptSimpleTips`，参数由`@Valid`直接修饰）在本模块中不存在，实际类为`ErrorCodeDemoController`（包`com.pddon.framework.demo.easyapi.errorcode`，路径前缀`/error`），接口改为`POST /error/login`、`GET /error/simpleTips`，并新增系统错误码抛出的`GET /error/systemError`以及错误码清单查询`GET /error/systemCodes`、`GET /error/businessCodes`；登录参数改为`@RequestParam`。

* 接口源码`ErrorCodeDemoController.java`

```java
package com.pddon.framework.demo.easyapi.errorcode;

import java.util.List;

import javax.validation.constraints.NotEmpty;

import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.validation.annotation.Validated;
import org.springframework.web.bind.annotation.GetMapping;
import org.springframework.web.bind.annotation.PostMapping;
import org.springframework.web.bind.annotation.RequestMapping;
import org.springframework.web.bind.annotation.RequestParam;
import org.springframework.web.bind.annotation.RestController;

import com.pddon.framework.easyapi.component.BusinessErrorCodeInterpreter;
import com.pddon.framework.easyapi.consts.ErrorCodes;
import com.pddon.framework.easyapi.dto.ErrorCodeDto;
import com.pddon.framework.easyapi.exception.BusinessException;

/**
 * 错误码使用示例。
 *
 * 类名不能与框架内置的 com.pddon.framework.easyapi.controller.ErrorCodeController 同名，
 * 否则默认 Bean 名称 errorCodeController 会冲突。
 */
@RestController
@RequestMapping("/error")
@Validated
public class ErrorCodeDemoController {

    @Autowired
    private BusinessErrorCodeInterpreter businessErrorCodeInterpreter;

    /**
     * 抛出已配置业务码的业务异常（USER_ACCOUNT_NOT_FOUND 使用自动生成码值）。
     */
    @PostMapping("/login")
    public void login(@RequestParam @NotEmpty String account, @RequestParam @NotEmpty String password) {
        if (!"admin".equals(account)) {
            throw new BusinessException("USER_ACCOUNT_NOT_FOUND").setParam(account);
        }
        if (!"123456".equals(password)) {
            throw new BusinessException("USER_PASSWORD_ERROR");
        }
    }

    /**
     * 抛出简单提示类业务异常，未配置业务码，使用默认业务错误码 200000。
     */
    @GetMapping("/simpleTips")
    public void simpleTips() {
        throw new BusinessException("系统在本月10-15号进行维护，给您带来的不便，敬请理解，谢谢！");
    }

    /**
     * 抛出系统错误码异常。
     */
    @GetMapping("/systemError")
    public void systemError() {
        throw new BusinessException(ErrorCodes.NOT_FOUND);
    }

    /**
     * 查询系统错误码清单，验证 systemErrorCodes 自定义码值生效。
     */
    @GetMapping("/systemCodes")
    public List<ErrorCodeDto> systemCodes() {
        return businessErrorCodeInterpreter.getSystemCodes();
    }

    /**
     * 查询业务错误码清单。
     */
    @GetMapping("/businessCodes")
    public List<ErrorCodeDto> businessCodes() {
        return businessErrorCodeInterpreter.getBussinessCodes();
    }
}
```

* 请求示例（默认端口8088）

```shell

curl "http://localhost:8088/error/simpleTips?appId=webApp&channelId=default&locale=zh_CN"
curl "http://localhost:8088/error/systemCodes?appId=webApp&channelId=default"
curl "http://localhost:8088/error/businessCodes?appId=webApp&channelId=default"
```
